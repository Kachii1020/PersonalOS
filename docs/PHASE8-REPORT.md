## Deviations and evidence boundaries

- The first client-secret implementation used the obsolete planned endpoint and received 404. The official current `/v1/realtime/client_secrets` contract then succeeded.
- The current `gpt-live-transcribe` endpoint returned `invalid_value: Turn detection is not supported for this transcription model`. Automatic mode therefore uses Web Audio RMS and an explicit buffer commit; server VAD is not claimed.
- The first physical Mac PTT request proved that OpenAI transcription and the existing Anthropic work-decision call are separate failure domains. The final transcript appeared before Anthropic returned its prepaid-credit error. The application did not reach Phase 7 reply generation or TTS, and the observed transcript is recorded exactly rather than treated as the intended phrase.
- The low-credit response originally exposed the provider's raw JSON and request ID because `workHttp` trusted any thrown numeric `status`. The hardened boundary exposes only explicitly marked application errors. The user later restored Anthropic credits; an authenticated work request and the physical voice turn both reached successful Phase 7 responses.
- Dedicated 54721 startup failed while its project lived under `/private/tmp` because the pgsodium root-key bind became a directory. Moving the same synthetic configuration under the user workspace removed that failure. A clean reset then applied 0001–0031 and the DB gate passed; the earlier failed starts are not counted as migration evidence.
- The 12:17 JST physical run returned `/voice/turns` 200, `/voice/speech` 200, heartbeat 200 and then session DELETE 200. Those records prove provider PCM delivery but not speaker output. Migration 0031 and the visible playback state were added so future runs distinguish receipt, playback start, completion and interruption.
- Live provider requests were executed, including two fixed 40-case TTS→Realtime runs. The visible project spend moved from `$1.01` before the runs to `$1.29` after them; this `$0.28` difference is observational and may include reporting delay, so it is not assigned as exact per-call billing. Local reservation rows created by app gates were removed with their test sessions.
- The OpenAI key is stored in the ignored Phase 8 local env and as a sensitive Vercel Production/Preview variable. After switching to the original Platform login, the visible `Default project` ID matched the key target (`proj_rgSnMAWCWenjcNLHAiohswWq`). The user saved a project spend limit and the page was re-read after all three evaluations showing `$1.30 / $5.00`, hard-limit behavior and a 100% ($5) alert. - The second Realtime failures were K03/K04/K09/K16, M03/M05/M07/M10 and N03/N07/N10. They include Korean initial-word substitutions, mixed proper nouns and numeric homophones. The file-model failures were K03/K07/K14/K17/M01/M03/M06/M07/M08. No case is relabeled through post-hoc corpus changes.

The process was stopped immediately; no completed 40-case score or generated-audio duration is claimed. Official documentation says higher delay can improve word error rate but must be benchmarked with representative microphones, so this remains a tuning signal rather than acceptance evidence.

- 24 complete browser conversations, latency percentiles, ten interruption samples and real iPhone/Mac microphone routing remain not run. These are release gates, not inferred from the focused transport checks.

Two real transport sessions were created in this pass, so `$0.025` is the conservative public-rate estimate if each incurred the 15-second minimum; the provider bill was not read and this is not reported as actual spend.
